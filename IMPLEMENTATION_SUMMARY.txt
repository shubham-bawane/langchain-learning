🏗️ ARCHITECTURE OVERVIEW
================================================================================

Pipeline Flow:
  START
    ↓
  [1] Manager Agent (Clarify Requirements)
    ├─ Clear? → Continue
    └─ Vague? → 🔴 INTERRUPT (Wait for user answers)
    ↓
  [2] UI/UX Agent (Design Journey)
    ↓
  [3] Web Designer Agent (Define Aesthetics)
    ↓
  [4] Code Generator (Generate HTML)
    ↓
  [5] Output Validator (Validate)
    ├─ Valid? → [6] File Writer → END
    ├─ Errors + Retries < 3? → Back to [4]
    └─ Retries ≥ 3? → END (Fail)

State Management:
  - Unified AgentState flows through all nodes
  - Each node reads and updates state
  - Session ID tracks entire workflow
  - LLM provider preserved throughout
